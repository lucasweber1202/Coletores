# Claude Code Instructions

Read and follow `MASTER_MACRO_COLLECTOR_GUIDELINES.md` in full before acting.

This repository is a governance/backlog hub. Create each actual collector as a standalone `collector_<source>_<dataset>` repository, not as a shared framework or hidden package inside this hub.

Use `intake/collector_demands.csv` as the authoritative demand backlog and `templates/COLLECTOR_REQUEST.md` as the required intake form. Ask for missing mandatory fields before generating collector files.

The master guideline overrides conflicting or stale examples in individual skill files. Never guess API documentation or silently fix findings during a report-only audit.
